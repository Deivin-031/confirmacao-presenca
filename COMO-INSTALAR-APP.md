# Aplicativo do painel administrativo

Os arquivos do site de convidados permanecem sem alterações. O painel em `admin.html` agora possui manifesto, ícones, service worker e melhorias de layout para celular.

## Publicação

Envie todos os arquivos deste ZIP para a raiz do repositório GitHub Pages, preservando os arquivos existentes. Aguarde a publicação e abra a URL HTTPS do painel (`.../admin.html`).

## Instalação

**Android (Chrome):** abra `admin.html`, entre no painel e use o botão **Instalar aplicativo** quando aparecer. Se não aparecer, abra o menu do Chrome e selecione **Instalar app** ou **Adicionar à tela inicial**.

**iPhone (Safari):** abra `admin.html`, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

O login Firebase continua obrigatório. A consulta e alteração de convidados, presentes e pagamentos requer conexão com a internet. Não são armazenados dados pessoais no cache do aplicativo.

**Nota:** o navegador pode não oferecer instalação imediatamente. HTTPS, ícones e manifesto precisam estar acessíveis após publicação. O app é um PWA, não um aplicativo de loja.
